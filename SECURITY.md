# Security Policy

## Supported versions

`mcp-sinim` has not yet reached a 1.0 release (its version numbers look like
`0.x.y`). Under [semantic versioning](https://semver.org/#spec-item-4), that
means the public API can still change between minor versions without a major
version bump — this is a normal, deliberate stage for a young library, not a
statement about code quality. Only the latest release published on PyPI
receives security updates; there is no long-term-support branch yet.

## Reporting a vulnerability

Please report vulnerabilities privately through the repository's GitHub
Security Advisories page by selecting **Report a vulnerability**. If private
reporting is unavailable, contact Maykol Medrano at mmedrano2@uc.cl.

Please do not open a public issue for an undisclosed vulnerability. Include a
description, reproduction steps, affected versions, and any known mitigation.
